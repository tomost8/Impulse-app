# Project README

## Overview

This project is built with Bun and Expo, offering a fast and efficient development environment for React Native applications.

## Getting Started

Before starting, ensure you have Bun and Expo CLI installed. You can refer to the Expo documentation for detailed setup instructions.

## Installation

To install the dependencies, simply run:

```bash
bun install
```

## Scripts

For available scripts and usage instructions, check the scripts section in the package.json file. Common commands like starting the development server, building the app, and testing are all listed there.

## Key Dependencies

### Chat Functionality

The chat functionality is powered by react-native-gifted-chat, which provides a customizable and feature-rich messaging interface.

### UI Library

We use react-native-paper as our primary UI library, offering a clean and responsive Material Design system for React Native.

### Expo-Blur Issue

The current official version of expo-blur has some issues. For now, we are using a local version of the library. Once the official version is fixed, we will update it to the latest stable release. Please keep an eye on updates and adjust your dependencies accordingly.
